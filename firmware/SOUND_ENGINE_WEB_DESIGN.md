# Дизайн веб-интерфейса звуковой схемы

> Примечание: документ исторический. Сборка переведена на ESP-IDF 6.0
> (`firmware\idf_build.ps1`); упоминания `pio run`/PlatformIO относятся к
> ранним версиям.

Документ описывает UI/UX звуковой подсистемы в единой странице `web_ui.html`.
Связан с: `SOUND_ENGINE_IMPLEMENTATION.md` (§8 карта, §10 интерфейс, §21 роадмап),
`SOUND_ENGINE_ROADMAP.md` (этап **R5**). Реализация — по R5.

Принцип: **ничего лишнего** — переиспользуем существующие стили/паттерны, добавляем
минимум новых классов и JS; страница остаётся single-file, без фреймворков.

---

## 1. Принципы дизайна
1. **Единый визуальный язык** с текущей страницей: `--bg/--panel/--accent`, `.panel`,
   `.panel-hd`, `.cv-card`, `.btn`, `.field`, `.row`, `.hint`, `.log`, модалки.
2. **Мобильный приоритет** (страница открывается с телефона через SoftAP): тап-цели ≥42 px,
   горизонтальные матрицы со скроллом → аккордеон на узких экранах.
3. **Прогрессивное раскрытие**: панели свёрнуты, данные грузятся при открытии
   (`togglePanel`), тяжёлые матрицы не рендерятся, пока не открыты.
4. **Оптимистичный UX + журнал**: мгновенно применяем в UI, ошибку — в `log()`.
5. **Один источник правды** — данные из REST, без локального дублирования конфигурации.
6. **Предпросмотр — на плате**, не в браузере (кнопка `▶` шлёт `/api/audio/play`).

## 4. Экран «Функции» (карта)
Переработка панели «Настройка функции F» (§8). Три вкладки: **Выходы · Звуки · Логика**.

### 4.1. Вкладка «Выходы» — матрица `выход × (F × В/Н)`
Как «Карта выходов» SoundGT (image018). Desktop — таблица со скроллом:

```
┌ Функции ──────────────────────────────────────────────────────────────┐
│ [ Выходы ]  [ Звуки ]  [ Логика ]        В — вперёд · Н — назад        │
│ ┌────────────┬──────────┬──────────┬──────────┬─────┬──────────┐       │
│ │ выход      │ F0(Свет) │ F1       │ F2       │ …   │ F28      │  ← sticky
│ │            │  В   Н   │  В   Н   │  В   Н   │     │  В   Н   │      │
│ ├────────────┼──────────┼──────────┼──────────┼─────┼──────────┤       │
│ │ Свет вперёд│ [☑] [ ]  │ [ ] [ ]  │ [ ] [ ]  │     │ [ ] [ ]  │      │
│ │ Свет назад │ [ ] [☑]  │ [ ] [ ]  │ [ ] [ ]  │     │ [ ] [ ]  │      │
│ │ AUX1       │ [ ] [ ]  │ [☑] [☑]  │ [ ] [ ]  │     │ [ ] [ ]  │      │
│ │ … (9 строк)│          │          │          │     │          │      │
│ └────────────┴──────────┴──────────┴──────────┴─────┴──────────┘       │
└────────────────────────────────────────────────────────────────────────┘
```
- Клик по ячейке — создать/удалить привязку `OUTPUT` c `dir=В/Н`.
- Привязка без направления отображается двумя «полугалочками» или отдельным бейджем
  «В/Н» (вторичный селектор в мини-поповере ячейки: направление/состояние/эффект).

**Мобильный (≤600px)** — аккордеон по F-клавишам (те же данные):
```
F1  ▸  Свет вперёд · В ☑   AUX1 · В ☑   AUX1 · Н ☑   ⚙
F2  ▸  —
```

### 4.2. Вкладка «Звуки» — матрица `таблица × (F × В/Н)`
```
│            │ F1        │ F2        │ F3        │ …                     │
│ таблица    │  В    Н   │  В    Н   │  В    Н   │                       │
│ M to S     │  —    —   │  —    —   │  —    —   │  (двигатель — старт)  │
│ Glocke     │ [gl] [gl] │  —    —   │  —    —   │                       │
│ Pfiff      │ [ph] [— ] │  —    —   │  —    —   │                       │
```
- В ячейке — короткое имя таблицы; клик ставит/снимает привязку `SOUND`.
- Кнопка **«Создать таблицу»** ведёт в «Звук: Доп. звуки» (или создаёт пустую).
- Специальные строки-логика вынесены во вкладку «Логика».
- По MD Prog (§22.4) звуковые таблицы назначаются на `F8..F12` вперёд/назад; у нас
  диапазон шире — `F0..F28`. Таблицы **по состоянию** (`Стоим/Едем/Свет` × В/Н) — отдельные
  строки со `state`/`dir` и без F-клавиши (`fn=0xFF`).

### 4.3. Вкладка «Логика»
Список логических функций (Drive Hold, Dynamic Brake, Coast, Notch ±, Mute,
стоп двигателя, смена направления звука, **кнопки отмены звука по состояниям**
`MUTE_STOP/MOVE/LIGHT` — как «Кнопка отмены звука» в MD Prog, §22.4) — `FUNC_TARGET_LOGIC`:
```
F9  [☑] Drive Hold        условие: В/Н любое · едет
F11 [ ] Coast             условие: любое
F12 [☑] Dynamic Brake     условие: едет/тормозит
```
Строка: `F-клавиша · чекбокс · имя · селект условия`.

### 4.4. Поведение
- `loadFuncMap()` грузит `GET /api/func-map?view=matrix`; рендерятся только активная
  вкладка (кэш по подписи, как `slotsSig()`).
- Тоггл ячейки → `POST /api/func-map` (привязки), оптимистично; при ошибке — откат + `log()`.
- Не перерисовывать матрицу на каждом `/api/status`-poll.

## 5. Экран «Звук: Схема»
```
┌ Звук: Схема ───────────────────────────────────────────────────── ▸ ┐
│ Тип: [Выкл] [Дизель] [Паровоз] [Электровоз]      [Шаблон ▾]         │
│ Клавиша старта: [F1 ▾]   ☑ Синхронизировать движение со звуком      │
│ ● двигатель вкл · таблица D2 · скор 42 · rate 1120 · нагрузка 0.3   │
│ ┌────────┐   ┌────────┐   ┌───────────┐   ┌──────┐   ┌──────┐        │
│ │ M to S │ → │  Stop  │ → │ Stop to D1│ → │  D1  │ ⇄ │  D2  │ …      │
│ │ пуск   │   │  ХХ    │   │ трогание  │   │ ход  │   │ ход  │        │
│ └────────┘   └────────┘   └───────────┘   └──────┘   └──────┘        │
│ ┌──────┐ ┌──────┐ ┌────────┐ ┌────────┐  (переходные и A/CX)         │
│ │  A1  │ │ CX1  │ │D1→A1   │ │D1→CX1  │                              │
│ └──────┘ └──────┘ └────────┘ └────────┘                              │
│ ⚠ 2 предупреждения · [Проверить]                                    │
└──────────────────────────────────────────────────────────────────────┘
```
- **Карта состояний** — кликабельные `.snd-node`; цвет обводки активного состояния
  обновляется из live-статуса (sub-строка `.snd-live`).
- Карточка показывает: имя, тип (`Loop`/`конечная`), число треков, ссылки переходов
  (`→ D2`, `→ Stop`), предупреждение, если граф разорван/пусто.
- **Редактор таблицы** — модальное окно (см. §5.1).
- Тип проекта фиксируется при создании (переключение — с `confirmDialog()`).
- Пусто (`type=NONE`): баннер «Схема выключена, используется режим слотов» + кнопки
  «Создать дизель/паровоз/электровоз».

### 5.1. Модальный редактор таблицы
```
┌ Таблица: D1 (дизель) ────────────────────────────────────────────┐
│ Имя [D1________]                  ☑ Не включать без двигателя     │
│                                                                   │
│ Группа 1 (обычная)                                                │
│   Init [файл ▾]   Loop [файл ▾]   End [файл ▾]                    │
│ Группа 2..4 (пар: цилиндры 2/3/4)                                 │
│   Init [файл ▾]   End  [файл ▾]                                    │
│                                                                   │
│ Max скорость [130] → [D2 ▾]      Min скорость [1]  → [Stop ▾]      │
│ Max ускорение [ 30] → [A1 ▾]     Max замедление [-30] → [CX1 ▾]    │
│ Окончание [ ▾ ]                  Ускорение звука [20]              │
│ Min проигрышей [0]   Max [0]                                      │
│                                                                   │
│ [▶ Прослушать]   [Копировать]   [Удалить]      [Отмена] [Сохранить]│
└───────────────────────────────────────────────────────────────────┘
```
- «файл ▾» — `<select>`, заполняется из `GET /api/audio/tracks` (слот/имя), плюс «—».
  **Не drag&drop** (мобильный UX и экономия JS).
- Ссылки на таблицы — `<select>` (имена), только существующие цели.
- `▶ Прослушать` — играет выбранный трек на плате (`/api/audio/play?slot=N`).
- Сохранение — `POST /api/sound/table?id=N`, затем перерисовка карты и live-lint.

## 6. Экран «Звук: Доп. звуки»
```
┌ Звук: Доп. звуки ──────────────────────────────────────────────── ▸ ┐
│ [+ Новая таблица]                                                   │
│ ┌ Whistle ───────┐ ┌ Whistle short ┐ ┌ Bell ─────────┐ ┌ … ┐        │
│ │ Init: wst_b.wav│ │ Short: ws.wav │ │ Init: bell_b  │ │   │        │
│ │ Loop: wst_l.wav│ │ (one-shot)    │ │ Loop: bell_l  │ │   │        │
│ │ End:  wst_e.wav│ │               │ │ End:  bell_e  │ │   │        │
│ │ [▶][✎][✕]      │ │ [▶][✎][✕]     │ │ [▶][✎][✕]     │ │   │        │
│ └────────────────┘ └───────────────┘ └───────────────┘ └───┘        │
│ По состоянию (× В/Н): Стоим ▾▾   Едем ▾▾   Свет ▾▾                   │
│ Кнопки отмены: Стоим [F…▾]  Едем [F…▾]  Свет [F…▾]                  │
│ Случайные:  [таблица ▾]  интервал [min]…[max] ×0.8 с  (max_plays!)  │
│ Пар: сдвиг цилиндров [min]…[max] шаг [inc]                          │
│ Тормозные колодки: max скор [255] · порог торм. [10] ·              │
│                    запас [3] · порог End [5]                        │
└─────────────────────────────────────────────────────────────────────┘
```
- Карточки — те же `.cv-card`; `✎` открывает редактор таблицы (группа 1), `▶` — прослушать
  Loop, `✕` — удалить (с подтверждением).
- У звука до трёх ролей — Init / Loop / End (в MD Prog — `begin/loop/end`) и отдельный
  **Short**-трек (короткий гудок, §22.2) — в карточке отдельная строка.
- **Состояния** — по одной таблице на `Стоим / Едем / Свет` × **вперёд/назад** (как в
  MD Prog, §22.4): это `SOUND`-привязки `state`×`dir` с `fn=0xFF`.
- **Кнопки отмены** звука по состояниям — mute-логика `MUTE_STOP/MOVE/LIGHT`.
- «Случайные» — таблица + интервал min/max (ед. 0.8 с); обязательный `max_plays`
  (иначе предупреждение).
- **Пар** — блок «сдвиг цилиндров» (`min/max/inc`), показывается только для `type=STEAM`.
- «Колодки» — 4 числовых поля + подсказка «подгоняется под CV3/CV4».

## 8. Взаимодействия и состояния
- **Загрузка при открытии**: в `togglePanel()`:
  `if(show&&name==='fnmap')loadFuncMap(); if(name==='sound_scheme')loadSoundScheme();`
  `if(name==='sound_extras')loadSoundExtras(); if(name==='sound_params')loadSoundParams();`
- **Live-статус**: расширить существующий 3-секундный `refreshStatus()` полями
  `/api/sound/state` (активная таблица, engine on, rate, нагрузка) — одна строка `.snd-live`.
  Не перерисовывать карту/матрицу, только текстовые поля (сравнение по подписи).
- **Сохранение**: числовые поля — по `change` (не `input`), слайдеры — debounce 300 мс
  (как `volTimers`); тогглы/ячейки — сразу.
- **Ошибки**: `log('Звук', e.message)` + откат оптимистичного изменения.
- **Валидация/линт**: после сохранения — `GET /api/sound/lint`; проблемы показываются
  бейджем `⚠ N` и подсветкой карточек/ячеек; клик открывает список проблем.
- **Офлайн**: если `isOffline`, live-строка серая, кнопки сохранения `disabled`.

## 10. Доступность
- Все тапы ≥42 px (`.btn` уже), чекбоксы в матрице — обёртка `.cell` ≥20 px + padding.
- `aria-label` на иконочных кнопках (`▶`, `✎`, `✕`, `⚙`).
- Числовые поля `inputmode="numeric"`, `min/max`.
- Фокус — `:focus{border-color:var(--accent)}` (уже есть); Enter в поле — сохранить.
- Цвет не единственный носитель смысла: состояние дублируется текстом/глифом.

## 11. JS-структура (минимум, ~250 строк)
```
loadFuncMap(view)            // GET /api/func-map?view=matrix, рендер активной вкладки
toggleBinding(kind,fn,dir,id)// POST /api/func-map (оптимистично + откат)
loadSoundScheme()            // GET /api/sound/scheme → карта .snd-node
openTableEditor(id)          // модалка; selects из /api/audio/tracks
saveSoundTable(id)           // POST /api/sound/table?id=N
deleteSoundTable(id)         // DELETE (через POST ?action=delete)
loadSoundExtras()/saveSoundExtras()
loadSoundParams()/saveSoundParams()
renderSoundMatrix()          // вкладка «Звуки»
renderSoundMap()             // карта состояний
pollSoundState(d)            // из refreshStatus, обновляет .snd-live

```
Правила экономии: не строить DOM матрицы при каждом poll; использовать подпись данных
(`JSON`-хэш) и перерисовывать только при изменении; общий помощник `selectHtml()` для
`<select>` файлов/таблиц.

## 13. Что не делаем
- SPA/фреймворки, отдельные страницы, клиентский drag&drop-граф.
- Предпросмотр WAV в браузере (только на плате).
- Дублирование привязок F между «Функциями» и «Доп. звуками».
- Тяжёлый рендер матриц при каждом опросе статуса.
- Новые цветовые темы/токены сверх существующих.
