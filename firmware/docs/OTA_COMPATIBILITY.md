# Совместимость OTA и платформы

Короткий контракт: что можно обновить по воздуху, а что требует USB.

Текущий релиз — **0.31**; `layout_version` платформы — **1** (структура ниже не
менялась).

## Главное правило

OTA пишет **только раздел приложения `ota_x`** (`ota_0`/`ota_1`). Загрузчик,
таблица разделов, `otadata`, NVS и eFuse не обновляются. Всё, что меняет
разметку или низкоуровневые настройки чипа, доставляется только полным образом
по USB.

## Замороженная платформа v1

| Раздел / образ | Смещение | Размер | Обновляется по OTA |
|---|---|---|---|
| `bootloader` | 0x0 | ≤ 0x8000 | нет |
| таблица разделов | 0x8000 | 4 КБ | нет |
| `nvs` | 0x9000 | 64 КБ | нет |
| `phy_init` | 0x19000 | 4 КБ | нет |
| `otadata` | 0x1A000 | 8 КБ | нет |
| `ota_0` (app) | 0x20000 | 0x1E0000 | да (цель) |
| `ota_1` (app) | 0x200000 | 0x1E0000 | да (приёмник) |
| `coredump` | 0x3E0000 | 128 КБ | нет |

- Слот приложения: **0x1E0000** (1920 КБ); загрузчик: не более **0x8000**.
- Flash: **4 МБ, DIO, 80 МГц**. PSRAM: **quad**. Secure boot, шифрование flash
  и anti-rollback **выключены**.

## Требует USB

- смена таблицы разделов или смещений/размеров;
- смена загрузчика, включая boot-safe hook v0.29;
- смена flash/PSRAM и их режимов;
- включение secure boot, шифрования flash или anti-rollback;
- приложение больше слота.

## Безопасно по OTA

- код приложения;
- схема NVS с миграцией данных;
- звуковые пакеты;
- веб-UI.

Новые разделы по OTA **не** создаются — никогда.

## Контракт совместимости

Значения зафиксированы в `main/platform_compat.h` и `tools/ota_compat.json`,
сверяются `test/test_ota_compat.py`. При расхождении CI падает с
`USB-REQUIRED:` и обновление по воздуху не выпускается.

## Поведение при несовпадении

Движение запрещено, OTA не подтверждается, веб-диагностика доступна, требуется
обновление по USB.

## Проверка OTA-образа

Имя проекта в образе должно быть `soft_decoder_v3`. Чужой образ отклоняется,
текущая загрузка не меняется.

## Откат

Новая прошивка стартует как `PENDING_VERIFY` только при первой загрузке. После
`esp_ota_mark_app_valid_cancel_rollback()` откат возможен только по USB.

## Чек-лист релиза и восстановление

1. Проверить `layout_version`, размеры и прохождение контракта в CI.
2. Убедиться, что версия приложения совпадает с `version.txt`.
3. При проблеме — USB download mode и заводской полный образ.

## Намеренная смена платформы

1. Поднять `layout_version` в заголовке и в JSON.
2. Собрать полный USB-образ: bootloader + partitions + otadata + app.
3. Добавить в release notes пометку «USB required».
4. Никогда не публиковать только app.
