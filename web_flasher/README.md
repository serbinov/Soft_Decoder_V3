# ADDITIPUS Прошивальщик (Web Serial)

Прошивка **без сторонних программ** — только браузер Chrome/Edge и USB-кабель.
Заливает прошивку (ROM-загрузчик ESP32-S3) и звуки во внешнюю память (LittleFS).

## Как пользоваться (3 шага)

1. Соберите файлы прошивки: `firmware\build_flash_tool_files.bat` → в `release\flash_download_tool\`.
2. Откройте `web_flasher\index.html` в **Chrome или Edge**:
   - **«Выбрать папку прошивки»** — любую папку с .bin файлами (имена не важны,
     распознаются по содержимому: загрузчик, таблица разделов, ota_data, прошивка).
   - **«Выбрать папку звуков»** — папку с WAV-файлами (можно не выбирать).
3. Вставьте USB и нажмите **«Прошить и загрузить звуки»**.

## Как это работает (два пути)

**Путь 1 — без кнопок (если прошивка на чипе работает):**
инструмент подключается по USB и за один PROV-сеанс заливает и новую прошивку
(команда `FW`, OTA-слот через `esp_ota`), и звуки (`PUT`). Режим загрузчика не нужен,
кнопки жать не нужно. Прошивка перезагружается в новую версию.

**Путь 2 — ROM-загрузчик (чистый чип / первая прошивка):**
инструмент автоматически переводит чип в режим загрузчика той же последовательностью
DTR/RTS (USBJTAGSerialReset), что и esptool (ключи Web Serial: `dataTerminalReady`/
`requestToSend`). Если автосброс не сработает — один раз **BOOT+RST** (инструмент
подхватит сам).

Всё остальное автоматически: порт, режим загрузчика, стирание, прошивка, перезагрузка,
загрузка звуков в слоты 1..N (по алфавиту имён — имена становятся подписями слотов).

## Возможности

- **Две отдельные папки** — прошивка и звуки выбираются независимо.
- **Без папки звуков** — прошивается только прошивка.
- **Автораспознавание файлов**: имена .bin и .wav могут меняться — файлы определяются
   по содержимому (магия 0xAA 0x50 — разделы, 0xE9 + esp_app_desc 0xABCD5432 — прошивка,
   размер — загрузчик/ota_data). Офсеты: bootloader @ 0x0, partitions @ 0x8000,
   firmware @ 0x20000 (слот ota_0); ota_data — читается из `partitions.bin`
   (метка `otadata`, сейчас 0x1A000), поэтому остаётся верным при смене разметки.
- **Порт**: показывается чип и USB ID (Web Serial не отдаёт номер COM). Порт открывается
  автоматически при нажатии «Прошить» и закрывается после операции. Для обновлений через
  PROV (путь 1) соединение стабильное; для ROM-прошивки (путь 2) — переподключение с флудом
  SYNC и подхватом BOOT+RST.
- **Список файлов**: для каждого — имя, размер, прогресс-бар и скорость заливки.
- Нативный USB-Serial-JTAG (VID 303A) — без смены скорости; USB-UART мост
  (CP210x/CH340) — автоматическое переключение на 921600 после PROV-OK.

## Требования

- Chrome / Edge (Web Serial API). Safari/Firefox не поддерживают.
- Работает с `file://` (двойной клик по файлу).

## Ограничения

- Первая прошивка чистого чипа идёт только через ROM-загрузчик (нужен один раз BOOT+RST
  или `firmware\flash_firmware.bat`). Обновления поверх работающей прошивки — без кнопок.
- Путь 1 (PROV) обновляет только приложение (firmware.bin) в OTA-слот; загрузчик и таблицу
  разделов обновляет путь 2 (ROM).
- Первый запуск: Chrome один раз попросит выбрать порт — выберите порт декодера.
