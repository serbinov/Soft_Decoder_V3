# ADDITIPUS — панель прошивки (веб)

Веб-страница — **настройка, статус, запуск и статистика**. Саму прошивку выполняют
**скрипты** проекта (`firmware\flash_esptool.ps1`, `web_flasher\make_ota.ps1`) —
те же, что и при ручном запуске, поэтому используется проверенный на железе
механизм входа в режим загрузчика.

## Быстрый запуск

1. Один раз соберите файлы: `firmware\build_flash_tool_files.bat` →
   `release\flash_download_tool\`.
2. Запустите **`web_flasher\start_flasher.bat`** (двойной клик). Он поднимает
   локальный сервер на встроенном PowerShell (**ничего устанавливать не нужно**)
   и открывает браузер.
3. В панели посмотрите блок **«Состояние»** и нажмите нужное действие.

Сервер **завершается сам**, когда закрыты все вкладки страницы (через ~12 с) —
порт освобождается, и повторный запуск не падает с «порт занят».

## Три действия

| Кнопка | Что делает | Скрипт |
|---|---|---|
| **Создать OTA** | создаёт `release\ADDITIPUS_AURA-X_v<ver>_OTA.bin` для обновления через веб-интерфейс декодера | `make_ota.ps1` |
| **Прошить** | прошивка по USB: загрузчик + разделы + приложение; настройки/NVS сохраняются | `flash_esptool.ps1` (esptool) |
| **Прошить + звуки** | то же плюс заливка звуков (WAV) во внешнюю память | `flash_esptool.ps1 -Sounds` + `provision_sounds.ps1` |

Прошивка идёт через **esptool** — он сам проверяет записанное
(`Hash of data verified`), поэтому это надёжный путь. Панель ищет esptool так:

1. автономный **`firmware\tools\esptool\esptool.exe`** — уже лежит в проекте
   (официальная standalone-сборка **esptool v5.4.0**, ~15 МБ, **без установки и без Python**);
2. иначе — esptool из установленного ESP-IDF (`python -m esptool`);
3. если ничего нет — автономный `flash_standalone.ps1` (чистый PowerShell).

Для переноса на другую машину достаточно скопировать проект целиком (включая
`firmware\tools\esptool\esptool.exe`) — ни Python, ни ESP-IDF не нужны.

## Вкладки

- **Прошивка** — состояние, три действия и **цветной лог**: `[INFO]` синий,
  `[OK]` и `Hash of data verified` зелёные, `[WARN]` жёлтый, `[ERROR]`/`ошибка`
  красные, проценты записи — серые.
- **Статистика** — сводка (**всего / успешно / ошибок / последняя**) и **история
  прошивок**: дата, действие, порт, **MAC чипа**, результат, версия, размер,
  число звуков, длительность, метод (esptool vX). История хранится в файле
  **`web_flasher\stats.json`** (до 500 записей) и видна при следующем открытии.
  MAC берётся из USB-серийника ESP32-S3 (без входа в режим загрузчика).

Вывод скрипта идёт в лог **в реальном времени**: порт, вход в режим загрузчика,
запись с прогрессом, проверка хеша, перезагрузка, код завершения.

## Состояние (блок «Состояние»)

Панель показывает: **порт платы** (авто-определение по USB VID_303A/PID_1001),
найден ли **ESP-IDF** (для прошивки не требуется), сколько **файлов прошивки**
и **звуков** найдено.

## Требования

- Windows 10/11 — встроенный PowerShell, без установки. Можно использовать на
  чистой машине: только Chrome/Edge + USB-кабель.
- Chrome / Edge для страницы.

## Почему веб только для настройки

Браузерный Web Serial не на всех машинах надёжно уводит ESP32-S3 в режим
загрузчика. Скрипты делают это так же, как esptool, и проверены на реальной плате,
поэтому прошивка идёт через них, а веб оставлен для удобной настройки, запуска и
показа лога.

## Устранение неполадок

- **Порт не найден** — подключите USB и нажмите «Обновить»; при необходимости
  зажмите **BOOT** и коротко нажмите **RST**.
- **Нет файлов прошивки** — соберите `firmware\build_flash_tool_files.bat`.
- **Страница без сервера** — запускайте через `start_flasher.bat`, а не двойным
  кликом по `index.html` (тогда нет доступа к скриптам и статусу).
