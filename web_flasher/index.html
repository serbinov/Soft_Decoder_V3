Панель прошивки ADDITIPUS

Прошивку выполняют скрипты (flash_esptool.ps1, make_ota.ps1), сборка бинарника — build_firmware.bat. Эта страница — настройка, статус, запуск и статистика. Открывать через start_flasher.bat (Chrome/Edge).

Действия

Собирает BIN из исходников и публикует release\flash_download_tool\. Нужен ESP-IDF.

Создаёт release\ADDITIPUS_AURA-X_vX_OTA.bin для обновления через веб-интерфейс декодера.

Собирает release\ADDITIPUS_sounds.asp из папки SOUND\ для загрузки на странице «Загрузка звуков» декодера (до 400 звуков, IMA ADPCM ~4×, реальные имена). Нужен Python 3.

Полная прошивка по USB (загрузчик + разделы + приложение). Настройки/NVS сохраняются.

То же плюс заливка WAV из папки SOUND\ во внешнюю память (до 20 звуков, по UART).
